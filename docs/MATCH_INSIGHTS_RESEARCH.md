# 경기 상세: 관전자가 필요한 데이터 (2026-10-30)

## 기준
경기를 보는 사람이 먼저 알고 싶은 것은 현재 상황, 어느 쪽이 우세한지, 그 원인과 중요한 선수다. 보기 좋은 그래프보다 실제 경기의 기록인지, 같은 시점인지, 누락이 있는지 확인한다. 공급 시각은 실제 플레이가 일어난 시각과 다르다. 데이터가 없다면 값을 추정하지 않는다.

## 종목별 가치와 현재 상태

축구 점유율은 단독으로 경기 우세를 단정하기 어렵고 슈팅·유효슈팅과 함께 봐야 한다. [Sofascore 설명](https://www.sofascore.com/news/understanding-the-effect-of-possession-pass-success-percentage-and-shots-on-target-in-football-matches). 야구의 승리 확률은 점수뿐 아니라 이닝·아웃·주자와 과거 상황별 결과가 필요한 모델 값이다. [MLB Baseball Savant 설명](https://baseballsavant.mlb.com/game-strategy-explorer). 현재 SPORTON의 농구 그래프는 득점 시점 점수 차이며 승리 확률이 아니다.

## 우선순위
1. 실제 제공된 숫자를 양 팀에서 같은 라벨과 같은 경기 기준으로 비교한다. 누락은 —로 표시하고 0으로 바꾸지 않는다. 이번 변경은 팀 기록 비교와 읽기 쉬운 가로 막대, 국내 농구 주요 선수 라벨을 적용한다.
2. 통계별 업데이트 시각과 팀별 부분 실패를 계속 표시하고 공급 장애를 해결한다. 2026-10-30 확인 당시 국내 제공처는 운영 API에서 502였다. 이 문제를 해결하지 않고 국내 데이터가 실시간이라고 보장할 수 없다.
3. 국내외 현역 경기에서 실제 제공되는 선발/교체, 부상, 타석/주자, 슈팅 좌표를 조사한다. 리그별 예외와 제공 시점, 데이터 이용 권한을 확인하고 기록한 다음 화면을 추가한다.
4. 승리 확률, xG, 모멘텀은 정의·모델·출처·시점이 확인된 경우에만 도입한다. 근거 없이 기존 점수나 점유율만으로 만들어 보여주지 않는다.
5. 실제 관전자 5~10명에게 30초 안에 현재 상황과 우세 원인을 찾는 과제를 주고 막힌 지점 및 재방문을 확인한다. 아직 수행하지 않은 연구다.

프로토타입 수치는 표본 경기에서 확인한 값이며 모든 경기/리그의 제공을 보장하지 않는다. 팀 기록 막대는 두 값의 비율을 시각화하며 수치가 클수록 좋은 기록이라는 뜻은 아니다.
